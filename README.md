# مداد

مساحة عمل عربية لك ولفريقك: مستندات بالبلوكات، وقواعد بيانات (جدول، لوحة، تقويم)، ولوحات بيضاء، وكل صفحة لها وجهان: مستند ولوحة.

## البنية

```
index.html                 الصفحة، شاشة الدخول، ولوحة الفريق
css/style.css              تصميم المحرر (ألوان فاتح/داكن عبر متغيرات CSS)
css/cloud.css              تصميم الدخول والفريق
js/config.js               رابط Supabase والمفتاح العام (anon)
js/app.js                  المحرر نفسه — يبدأ عبر startMidad(opts)
js/cloud.js                الدخول، مساحات العمل، المزامنة، التحديث اللحظي، الدعوات
supabase/migrations/       مخطط قاعدة البيانات
مداد.html                  النسخة الأولى (ملف واحد، تخزين محلي) للرجوع إليها
```

لا يوجد build: الملفات تُخدم كما هي (GitHub Pages أو أي استضافة ثابتة).

## قاعدة البيانات

مشروع Supabase **مستقل خاص بمداد** (لا علاقة له بأي مشروع آخر)، والجداول في مخطط **`midad`**.

| الجدول | المحتوى |
|---|---|
| `midad.workspaces` | مساحات العمل |
| `midad.members` | الأعضاء وصلاحياتهم: `owner` / `editor` / `viewer` |
| `midad.invites` | دعوات بالبريد، تتحول لعضوية عند أول دخول |
| `midad.pages` | كل صفحة (بلوكاتها، عناصر لوحتها، تعليقاتها) في صف `jsonb` |

كل الجداول محمية بـ RLS: لا يرى المستخدم إلا مساحات هو عضو فيها، والقارئ لا يكتب، ودور `anon` لا يصل لشيء.

### الإعداد لأول مرة

1. أنشئ مشروع Supabase جديداً، وضع رابطه ومفتاحه العام (anon / publishable) في `js/config.js`.
2. **SQL Editor** ← الصق `supabase/migrations/001_midad_schema.sql` ← Run.
3. **Project Settings ← Data API ← Exposed schemas**: أضف `midad`.
4. **Authentication ← URL Configuration**: اجعل Site URL رابط GitHub Pages، وأضفه أيضاً في Redirect URLs (لروابط تأكيد البريد واستعادة كلمة المرور).

## التشغيل محلياً

```bash
npx serve .
```

## ملاحظات

- الصور حالياً تُحفظ داخل الصفحة نفسها (data URL). للصور الكثيرة يُفضّل نقلها إلى Supabase Storage.
- عند تعديل شخصين نفس الصفحة في نفس اللحظة، آخر حفظ هو الذي يبقى.
